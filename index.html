SQL Serverless Database

เมื่อเชื่อมต่อ Cloudflare D1 แล้ว ข้อมูลจะถูกจัดเก็บบนคลาวด์แบบ Real-time ช่วยให้สามารถใช้งานพร้อมกันได้หลายเครื่อง ทั้งคอมพิวเตอร์ห้องพยาบาล แท็บเล็ต หรือมือถือ และยังคงมีระบบสำรองข้อมูลในเครื่องอัตโนมัติ

🖥️ ติดตั้งเป็นแอปพลิเคชันหน้า Desktop

ท่านสามารถเปิดใช้งานระบบในรูปแบบโปรแกรมเดสก์ท็อป (Standalone Window) ไร้แถบ URL กวนใจ เปิดได้รวดเร็วเหมือนโปรแกรมทั่วไป

📖 ดูวิธีเปิดไฟล์สร้างทางลัดบน Desktop

📥 สำรองข้อมูลเป็นไฟล์ (Export JSON)

ดาวน์โหลดไฟล์สำรองข้อมูล (.json) เพื่อเก็บไว้ในเครื่องหรือ Flash Drive สำรองไว้เป็นประจำ

📤 กู้คืนข้อมูลจากไฟล์สำรอง (Restore)

เลือกไฟล์สำรองข้อมูล (.json) ที่เคยดาวน์โหลดไว้ เพื่อนำข้อมูลทั้งหมดกลับเข้าสู่ระบบ

🧪 ข้อมูลตัวอย่างสำหรับทดสอบระบบ (Demo Data)

หากต้องการดูตัวอย่างกราฟและสถิติ ท่านสามารถกดปุ่มเพื่อเพิ่มข้อมูลจำลองของนักเรียน ม.1 - ม.6 และบุคลากรได้ทันที

⚠️ ล้างข้อมูลทั้งหมดในระบบ

การกดปุ่มนี้จะลบรายการบันทึกทั้งหมดออกจากระบบ โปรดสำรองข้อมูลก่อนทำรายการ
