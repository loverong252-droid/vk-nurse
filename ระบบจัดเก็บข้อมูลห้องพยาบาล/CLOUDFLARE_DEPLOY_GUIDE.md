# คู่มือการนำระบบห้องพยาบาลขึ้น Cloudflare Pages + Cloudflare D1 Database

คู่มือฉบับนี้จัดทำขึ้นสำหรับ **โรงเรียนวิสุทธิกษัตรี จ.สมุทรปราการ** เพื่อนำระบบห้องพยาบาลขึ้นใช้งานบน **Cloudflare (ฟรี 100%)** ทำให้สามารถใช้งานผ่านอินเทอร์เน็ตได้พร้อมกันหลายอุปกรณ์ ทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## ขั้นตอนที่ 1: สร้างฐานข้อมูล Cloudflare D1 (Database)

1. เข้าสู่ระบบที่ [https://dash.cloudflare.com/](https://dash.cloudflare.com/)
2. ที่เมนูด้านซ้าย เลือก **Storage & Databases** -> **D1 SQL Database**
3. คลิกปุ่ม **Create Database**
4. ตั้งชื่อ Database Name: `vk-nurse-db` แล้วคลิก **Create**
5. เมื่อสร้างเสร็จ ให้คลิกเข้าไปที่ฐานข้อมูล `vk-nurse-db` -> เลือกแท็บ **Console**
6. เปิดไฟล์ `schema.sql` ในโฟลเดอร์นี้ คัดลอกโค้ด SQL ทั้งหมดไปวางในช่อง Console แล้วคลิก **Execute**
   *(คำสั่งนี้จะสร้างตาราง `nurse_records` พร้อมดัชนีสำหรับจัดเก็บข้อมูลนักเรียน บุคลากร และสัญญาณชีพทั้ง 6 ค่า)*

---

## ขั้นตอนที่ 2: นำโค้ดขึ้น Cloudflare Pages (Hosting & API)

### วิธี A: อัปโหลดโฟลเดอร์โดยตรง (Direct Upload - แนะนำ ทำได้ทันที)
1. ในหน้า Cloudflare Dashboard เมนูด้านซ้าย เลือก **Compute (Workers & Pages)** -> **Pages**
2. คลิก **Create an application** -> เลือกแท็บ **Pages** -> **Upload assets**
3. ตั้งชื่อโปรเจกต์ (Project name): `vk-nurse`
4. ลากโฟลเดอร์ `ระบบจัดเก็บข้อมูลห้องพยาบาล` ทั้งหมด (หรือไฟล์ทั้งหมดรวมถึงโฟลเดอร์ `functions`) ไปวางลงในกล่องอัปโหลด
5. คลิก **Deploy site** ระบบจะสร้างเว็บไซต์ให้ทันที พร้อมได้ลิงก์ เช่น `https://vk-nurse.pages.dev`

### วิธี B: เชื่อมต่อผ่าน GitHub (อัปเดตอัตโนมัติ)
1. นำโฟลเดอร์นี้ขึ้น GitHub Repository ของท่าน
2. ใน Cloudflare Pages เลือก **Connect to Git**
3. เลือก Repository แล้วคลิก **Save and Deploy**

---

## ขั้นตอนที่ 3: ผูกฐานข้อมูล D1 เข้ากับ Cloudflare Pages

เพื่อให้ระบบ API (`functions/api/...`) สามารถบันทึกและดึงข้อมูลจาก Cloudflare D1 ได้:
1. ใน Cloudflare Pages ให้คลิกที่โปรเจกต์ `vk-nurse`
2. ไปที่แท็บ **Settings** -> เมนูด้านซ้ายเลือก **Functions**
3. เลื่อนลงมาที่หัวข้อ **D1 Database Bindings** -> คลิก **Add binding**
4. ตั้งค่าดังนี้:
   - **Variable name**: `DB`  *(ตัวพิมพ์ใหญ่สองตัว ห้ามเปลี่ยนชื่อ)*
   - **D1 database**: เลือก `vk-nurse-db`
5. คลิก **Save**
6. ไปที่แท็บ **Deployments** -> คลิกปุ่ม `...` ที่การ Deploy ล่าสุด แล้วเลือก **Retry deployment** หรือสั่ง Deploy ใหม่ 1 ครั้งเพื่อให้การผูกฐานข้อมูลมีผลทันที

---

## ขั้นตอนที่ 4: การเปิดใช้งานและติดตั้งเป็น Desktop App

เมื่อติดตั้งบน Cloudflare เรียบร้อยแล้ว:
1. เปิดลิงก์เว็บไซต์ของท่าน (เช่น `https://vk-nurse.pages.dev`) บน Google Chrome หรือ Microsoft Edge
2. **สถานะคลาวด์**: สังเกตที่มุมขวาบน จะขึ้นสถานะ `🟢 Cloud D1 ออนไลน์`
3. **ซิงก์ข้อมูลเดิม**: 
   - ไปที่แท็บ **"💾 สำรองและจัดการข้อมูล"**
   - คลิกปุ่ม **"🔄 ซิงก์ข้อมูลในเครื่องขึ้น Cloudflare D1"** เพื่อส่งข้อมูลเดิมทั้งหมดขึ้นระบบคลาวด์
4. **ติดตั้งเป็น Desktop App**:
   - คลิกปุ่ม **"📲 ติดตั้งแอพ"** ที่มุมขวาบนของหน้าเว็บ เพื่อติดตั้งลงหน้าจอ Desktop ของคอมพิวเตอร์
   - หรือเปิดไฟล์ `สร้างไอคอนแอปบนเดสก์ท็อป.bat` ในเครื่องเพื่อสร้างไอคอนเข้าใช้งานได้ทันที
