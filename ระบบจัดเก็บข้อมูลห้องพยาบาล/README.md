# ระบบห้องพยาบาล โรงเรียนวิสุทธิกษัตรี จ.สมุทรปราการ

ระบบเว็บแอปพลิเคชันสำหรับจัดเก็บข้อมูลและวิเคราะห์สถิติการให้บริการห้องพยาบาล ออกแบบเฉพาะสำหรับ **โรงเรียนวิสุทธิกษัตรี อำเภอพระประแดง จังหวัดสมุทรปราการ** ทำงานได้แบบออฟไลน์ 100% ไม่ต้องใช้อินเทอร์เน็ต และไม่ต้องติดตั้งโปรแกรมเสริมใดๆ

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **ตราสัญลักษณ์โรงเรียน**: แสดงโลโก้โรงเรียนวิสุทธิกษัตรีเด่นชัดที่ **มุมขวาบน** ของระบบ พร้อมคำขวัญประจำโรงเรียน *"นตฺถิ ปญฺญา สมา อาภา"*
2. **ระบบคัดกรองผู้ใช้บริการตามโครงสร้างจริงของโรงเรียน**:
   - **นักเรียน**:
     - **ม.1 - ม.3**: แต่ละระดับชั้นมีห้องเรียนให้เลือก **ห้อง 1 ถึง 6**
     - **ม.4 - ม.6**: แต่ละระดับชั้นมีห้องเรียนให้เลือก **ห้อง 1 ถึง 12**
     - ระบุเลขที่นักเรียน
   - **บุคลากร / ครู**:
     - สลับไปช่องระบุตำแหน่ง / กลุ่มสาระการเรียนรู้ / แผนกงาน โดยอัตโนมัติ
3. **การบันทึกข้อมูลสะดวกรวดเร็ว (Quick Tag Buttons)**:
   - ปุ่มลัดเลือกอาการป่วยยอดนิยม (ปวดศีรษะ, ปวดท้อง, ไข้/ตัวร้อน, เป็นลม, แผลถลอก, ปวดประจำเดือน ฯลฯ)
   - ปุ่มลัดการรักษา (ให้นอนพัก, ทำแผล, 🚑 นำส่งโรงพยาบาล, เช็ดตัวลดไข้, ประคบเย็น/ร้อน ฯลฯ)
   - ปุ่มลัดการจ่ายยา (พาราเซตามอล, ยาแก้แพ้, ยาธาตุน้ำขาว/แดง, ผงเกลือแร่, ไม่ได้จ่ายยา ฯลฯ)
   - ระบบจดจำชื่อผู้บันทึก (ไม่ต้องพิมพ์ชื่อครูเวรซ้ำทุกครั้ง)
4. **ระบบสถิติและรายงานสรุป (Statistics & Analytics)**:
   - **สถิติรายสัปดาห์**: กราฟแท่งจำนวนผู้ป่วยแต่ละวัน (จันทร์-อาทิตย์)
   - **สถิติรายเดือน**: กราฟแนวโน้มทั้งเดือน และกราฟวงกลมแสดง 5 อาการเจ็บป่วยยอดฮิต
   - **สถิติรายปี**: กราฟแนวโน้มตลอด 12 เดือน และสถิติเปรียบเทียบระหว่างระดับชั้น ม.1 ถึง ม.6
   - ตารางสรุปจำแนกรายชั้นและห้องที่มาใช้บริการบ่อยที่สุด
5. **การพิมพ์และส่งออกข้อมูล**:
   - 🖨️ **พิมพ์ใบรับรองการนอนพักห้องพยาบาล (Print Slip)** เพื่อให้นักเรียนนำไปส่งครูประจำวิชา/ครูที่ปรึกษา
   - 🖨️ **พิมพ์รายงานสรุปสถิติ** สำหรับเสนอผู้อำนวยการหรือรองผู้อำนวยการ
   - 📥 **ส่งออกไฟล์ Excel (CSV)** รองรับภาษาไทย 100% (UTF-8 BOM)
6. **ความปลอดภัยและการสำรองข้อมูล**:
   - บันทึกข้อมูลลงเครื่องอัตโนมัติ (Offline Local Storage)
   - มีปุ่มดาวน์โหลดไฟล์สำรองข้อมูล (.json) และปุ่มกู้คืนข้อมูล
   - มีปุ่มโหลดข้อมูลตัวอย่างเพื่อทดสอบระบบได้ทันที

## 🚀 วิธีการเปิดใช้งาน

1. ไปที่โฟลเดอร์ `d:\ระบบจัดเก็บข้อมูลห้องพยาบาล`
2. ดับเบิ้ลคลิกที่ไฟล์ **`เริ่มเซิร์ฟเวอร์.bat`** (หรือดับเบิ้ลคลิกไฟล์ `เปิดระบบห้องพยาบาล.bat`)
3. ระบบจะเปิดขึ้นบนเว็บเบราว์เซอร์ และแสดงหน้าต่างเข้าสู่ระบบ ให้กรอก **Admin** และรหัสผ่าน **1234** เพื่อเริ่มใช้งานครับ
